# cpp_projects
A few C++ projects I created for my CS 14 course. These have been further modified from the original assignment descriptions to include various safety checks, such as handling non-integer inputs when one is requested.

**gambling_game.cpp**
A simple gambling game. The user picks three unique integers from 1-10 and their bet, and they try to get to 1500$ without losing it all.

**temperature_sort.cpp**
Uses temperatures.txt as its input. Displays the data of the file, information such as the averages and standard deviation and lets the user sift through the file to see what temperatures are on what indexes.

**name_rectangle.cpp**
The user can input their name and dimensions for a rectangle with a border character. They'll get an output of the rectangle filled with a repeating version of their name.
